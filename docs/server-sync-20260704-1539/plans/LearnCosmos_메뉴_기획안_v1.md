## 1. 전체 메뉴 구조

LearnCosmos의 메인 메뉴는 좌측 세로 메뉴를 기준으로 구성한다.

```text
홈
공지사항
개인학습
커뮤니티
크리에이터
사용자메뉴
```

데스크톱에서는 좌측 세로 메뉴를 고정하고, 공통 헤더 아래에는 현재 선택한 메인 메뉴의 하위 메뉴를 가로 탭으로 배치한다.

모바일에서는 좌측 메뉴를 사용하지 않고, 햄버거 메뉴 안에 메인 메뉴와 하위 메뉴, 사용자정보 메뉴를 함께 넣는다.

---

## 2. 데스크톱 레이아웃

```text
공통 헤더
├─ LearnCosmos 로고
└─ 로그인 또는 사용자정보

좌측 세로 메인 메뉴
├─ 홈
├─ 공지사항
├─ 개인학습
├─ 커뮤니티
├─ 크리에이터
└─ 사용자메뉴

공통 헤더 아래 하위 메뉴
└─ 선택된 메인 메뉴의 하위 메뉴 표시

본문
└─ 루미 안내 카드 + 작업 카드 + 영상 카드 + CTA

공통 푸터
```

좌측 메뉴는 서비스의 큰 구조를 담당한다. 상단 하위 메뉴는 현재 선택한 메뉴 안에서 세부 이동을 담당한다.

---

## 3. 모바일 레이아웃

```text
공통 헤더
├─ LearnCosmos 로고
└─ 로그인 또는 햄버거 메뉴

본문
└─ 현재 페이지 콘텐츠

공통 푸터
```

모바일 햄버거 메뉴 안에는 다음을 포함한다.

```text
홈
공지사항
개인학습
커뮤니티
크리에이터
사용자메뉴
로그인 / 로그아웃
알파 체험 신청
```

모바일 본문은 루미 안내 카드와 주요 CTA 중심으로 단순하게 구성한다.

## 4. 홈 메뉴

홈은 LearnCosmos의 공개 메인 페이지 역할을 한다.

```text
홈
├─ 바로 시작
├─ 서비스 체험
├─ AI 사용 안내
└─ 시작 전 확인
```

### 4.1 바로 시작

사용자가 배우고 싶은 주제를 바로 입력하는 영역이다.

주요 구성:

```text
- 루미 인사말
- 메인 문구
- CTA 입력창
- 바로 시작 버튼
- 예시 주제 칩
```

권장 문구:

```text
배우고 싶은 것이 하나의 행성이 됩니다.
```

입력창 문구:

```text
어떤 행성을 탐험하고 싶으세요?
```

버튼 문구:

```text
바로 시작
```

### 4.2 서비스 체험

LearnCosmos가 콘텐츠를 어떻게 학습 경험으로 바꾸는지 영상으로 보여준다.

주요 구성:

```text
- 루미 브리핑 카드
- LearnCosmos 서비스 체험 영상
- 알파 체험 신청 버튼
```

영상에서 다룰 내용:

```text
1. 배우고 싶은 주제 입력
2. AI가 행성탐험계획 생성
3. 지역과 지점 확인
4. 콘텐츠를 보며 목표·스킬·질문 기록
5. Explorer Diary에 결과물과 자기평가 저장
```

### 4.3 AI 사용 안내

AI 포인트와 BYOK를 안내한다.

주요 구성:

```text
- AI 포인트 설명 카드
- BYOK 설명 카드
- AI 포인트·BYOK 안내 영상
```

루미 안내 문구:

```text
처음에는 AI 포인트만 알아도 충분해요.
BYOK는 나중에 필요할 때 연결해도 괜찮아요.
```

### 4.4 시작 전 확인

가입 또는 알파 체험 신청 전에 확인해야 할 동의 문서를 안내한다.

주요 구성:

```text
- 서비스 이용약관
- YouTube API 이용약관
- 개인정보처리방침
- AI 사용 안내
- 외부 콘텐츠 안내
```

## 5. 공지사항 메뉴

공지사항은 서비스 운영 안내와 업데이트 소식을 제공한다.

```text
공지사항
├─ 전체 공지
├─ 서비스 공지
├─ 업데이트
└─ 점검 안내
```

각 항목의 역할은 다음과 같다.

```text
전체 공지: 모든 공지 모아보기
서비스 공지: 서비스 이용 관련 안내
업데이트: 기능 추가와 개선사항
점검 안내: 서버 점검, 장애, 작업 일정
```

루미 안내 예시:

```text
새로운 소식과 중요한 안내를 여기에서 확인할 수 있어요.
```

## 6. 개인학습 메뉴

개인학습은 LearnCosmos의 핵심 메뉴다.

```text
개인학습
├─ 오늘의 할 일
├─ 내 학습지도
│  ├─ 진행중인 코스
│  └─ 완료된 코스
└─ 코스 생성 및 검색
```

### 6.1 오늘의 할 일

`오늘의 할 일`은 개인학습의 첫 진입 화면이다.

역할:

```text
지금 바로 해야 할 학습 행동을 보여주고,
해당 학습 페이지로 바로 진입하게 한다.
```

표시할 항목:

```text
- 바로 이어갈 학습
- 기록이 필요한 학습
- 질문하고 해답찾기가 필요한 학습
- 결과물 정리가 필요한 학습
- 복습이 필요한 학습
```

할 일 카드 예시:

```text
행성: 파이썬 자동화 배우기
지역: 파일 다루기
지점: CSV 파일 읽기

루미 안내:
지난번에 여기서 멈췄어요.
오늘은 이 지점에서 작은 예제 하나만 실행해볼까요?

[바로 이어가기]
```

진입 흐름:

```text
오늘의 할 일
→ 할 일 카드 선택
→ 해당 코스 / 지역 / 지점 학습 화면
→ 코스별 학습하기 또는 학습일지 영역
```

### 6.2 내 학습지도

`내 학습지도`는 사용자가 가진 코스를 상태별로 확인하고 관리하는 화면이다.

내부 콘셉트로는 Galaxy Board를 유지할 수 있지만, 사용자에게 보이는 메뉴명은 `내 학습지도`로 고정한다.

```text
내 학습지도
= 내가 가진 학습 행성을 진행 상태별로 확인하고,
  필요한 코스의 학습 공간으로 진입하는 화면
```

#### 6.2.1 진행중인 코스

진행 중인 코스를 리스트로 보여주고 검색할 수 있게 한다.

```text
진행중인 코스
├─ 코스 리스트
└─ 코스별 메뉴
   ├─ 학습하기
   ├─ 학습일지
   ├─ 결과물 리스트
   ├─ 해당 커뮤니티
   └─ 크리에이터 피드백
      ※ 크리에이터 콘텐츠일 경우만 노출
```

코스 리스트 기능:

```text
- 코스명 검색
- 최근 학습순 정렬
- 완료율순 정렬
- 카테고리 필터
- 기록 필요 필터
- 막힌 지점 있음 필터
```

코스 카드 정보:

```text
- 코스명
- 진행률
- 최근 학습일
- 다음 지역
- 다음 지점
- 기록 필요 여부
- 결과물 작성 필요 여부
```

코스별 학습하기 역할:

```text
학습계획을 확인하고,
마지막 학습 지점 또는 선택한 지역/지점으로 진입한다.
```

구성:

```text
- 학습계획
- 지역 목록
- 지점 목록
- 마지막 학습 진입지점
- 바로 이어가기 버튼
```

코스별 학습일지 역할:

```text
해당 코스에서 남긴 관찰 기록, 막힌 점, 질문, 자기평가를 확인한다.
```

구성:

```text
- 관찰 기록
- 막힌 점
- 질문하고 해답찾기
- 반복 기록
- 자기평가
- 날짜별 기록 타임라인
```

코스별 결과물 리스트 역할:

```text
해당 코스에서 만든 결과물과 증거 자료를 모아 보여준다.
```

구성:

```text
- 결과물 제목
- 결과물 유형
- 작성일
- 연결된 지역/지점
- 파일/링크/이미지/녹음/코드 등
```

코스별 해당 커뮤니티 역할:

```text
해당 코스와 연결된 질문, 팁, 피드백, 같은 학습자 활동으로 진입한다.
```

초기에는 제한적으로 제공할 수 있다.

크리에이터 피드백 역할:

```text
크리에이터가 만든 콘텐츠 또는 코스일 경우,
학습자의 질문, 막힌 지점, 학습일지, 결과물에 대해
크리에이터에게 피드백을 요청하고 확인한다.
```

노출 조건:

```text
- 크리에이터가 만든 콘텐츠 또는 코스일 것
- 해당 크리에이터가 피드백 기능을 허용했을 것
- 학습자가 해당 코스를 내 학습지도에 추가했거나 진행 중일 것
```

#### 6.2.2 완료된 코스

완료한 코스를 리스트로 보여주고 검색할 수 있게 한다.

```text
완료된 코스
├─ 코스 리스트
└─ 코스별 메뉴
   ├─ 학습일지
   ├─ 결과물 리스트
   ├─ 복습하기
   ├─ 공유 설정
   ├─ 해당 커뮤니티
   └─ 크리에이터 피드백
      ※ 크리에이터 콘텐츠일 경우만 노출
```

완료된 코스 리스트 기능:

```text
- 코스명 검색
- 완료일 기준 정렬
- 결과물 있음 필터
- 공유 상태 필터
- 복습 필요 필터
```

완료된 코스 카드 정보:

```text
- 코스명
- 완료일
- 결과물 수
- 자기평가 요약
- 공유 상태
- 복습 가능 여부
```

완료된 코스별 학습일지:

완료된 코스의 학습 기록을 확인한다.

완료된 코스별 결과물 리스트:

완료된 코스에서 만든 결과물을 모아본다.

완료된 코스별 복습하기:

완료 후 일정 시간이 지난 코스를 다시 복습할 수 있게 한다.

완료된 코스별 공유 설정:

완료된 코스의 공개 여부와 공유 상태를 관리한다.

공유 상태 예시:

```text
비공개
공유 준비중
공유됨
공유 중지
```

완료된 코스별 해당 커뮤니티:

완료된 코스와 연결된 질문, 피드백, 결과물 공유, 같은 코스 학습자 활동으로 진입한다.

완료된 코스별 크리에이터 피드백:

크리에이터 코스일 경우 완료 후에도 결과물, 개선 기록, 복습 질문에 대해 피드백을 요청하거나 기존 피드백을 확인할 수 있다.

### 6.3 코스 생성 및 검색

`코스 생성 및 검색`은 새 코스를 만들거나, 기존에 시작할 수 있는 코스를 검색하고 내 학습지도에 추가하는 화면이다.

```text
코스 생성 및 검색
= 새 행성을 만들거나,
  추천 / 공유 / 크리에이터 코스를 찾아
  내 학습지도에 추가하는 화면
```

구성:

```text
코스 생성 및 검색
├─ 새 코스 생성
├─ 추천 코스 검색
├─ 공유 코스 검색
├─ 크리에이터 코스 검색
└─ 내 학습지도에 추가
```

새 코스 생성:

```text
- 주제 입력
- 학습 목표
- 난이도
- 선호 자료 유형
- 예상 기간
- 코스 생성 버튼
```

검색 유형:

```text
추천 코스
- LearnCosmos가 사용자 목표에 맞게 추천하는 코스

공유 코스
- 다른 사용자가 공유한 공개 코스

크리에이터 코스
- 승인된 크리에이터가 설계한 코스
```

검색 필터:

```text
- 키워드
- 카테고리
- 난이도
- 자료 유형
- 예상 기간
- 크리에이터 여부
- 공유 상태
```

주요 행동:

```text
새 코스 생성
→ AI가 행성탐험계획 생성
→ 내 학습지도에 추가
→ 코스별 학습하기 진입

코스 검색
→ 코스 미리보기
→ 내 학습지도에 추가
→ 바로 시작 또는 나중에 학습

바로 시작
→ 내 학습지도에 추가하면서 첫 학습 지점으로 진입
```

## 7. 커뮤니티 메뉴

커뮤니티는 개인학습에서 생긴 질문, 기록, 결과물, 루틴을 다른 학습자와 연결하는 공간이다.

```text
커뮤니티
├─ 커뮤니티 홈
├─ 커뮤니티 찾기
├─ 내 커뮤니티
└─ 만들기
```

초기 MVP에서는 준비 중 또는 제한 공개로 둘 수 있다.

코스별 커뮤니티와 전체 커뮤니티는 역할을 구분한다.

```text
전체 커뮤니티
= 주제별, 학습자별 커뮤니티 탐색 공간

코스별 해당 커뮤니티
= 특정 코스와 연결된 질문, 결과물, 피드백 공간
```

## 8. 크리에이터 메뉴

크리에이터는 학습 콘텐츠를 단순 업로드하는 사람이 아니라, 학습자가 목표와 스킬을 찾고 결과물을 남길 수 있도록 학습 경험을 설계하는 사람이다.

```text
크리에이터
├─ 크리에이터 소개
├─ 콘텐츠 만들기
├─ 그룹 코스
├─ 내 콘텐츠
└─ 피드백
```

초기 MVP에서는 `크리에이터 소개`와 `신청 안내` 중심으로 제공할 수 있다.

```text
AI 포인트
├─ 포인트 현황

```

### 9.3 BYOK 설정 및 사용정보

```text
BYOK 설정 및 사용정보
```

## 11. 최종 정리

LearnCosmos 메뉴 구조는 다음 기준으로 정리한다.

```text
1. 개인학습의 첫 화면은 오늘의 할 일이다.
2. 내 학습지도는 진행중인 코스와 완료된 코스를 관리하는 화면이다.
3. 코스별 세부 메뉴는 학습하기, 학습일지, 결과물, 커뮤니티로 구성한다.
4. 크리에이터 콘텐츠일 경우 크리에이터 피드백 메뉴를 조건부로 노출한다.
5. 코스 생성 및 검색은 새 코스 생성, 추천 코스, 공유 코스, 크리에이터 코스 검색을 한 화면에서 제공한다.
6. Explorer Diary는 독립 메뉴가 아니라 코스별 학습하기, 학습일지, 결과물 기능을 묶는 코스 상세 작업 공간으로 둔다.
7. 모바일에서는 좌측 메뉴 없이 햄버거 메뉴 안에 전체 IA를 통합한다.
```

## 12. 지점 학습 UX 상세 문서 연결

`코스별 학습하기` 안의 지점 학습 UX는 본 메뉴 기획안에서 깊게 다루지 않는다.

메뉴 기획안에서는 다음 범위까지만 정의한다.

```text
코스별 학습하기는 지역 / 선택적 하위지역 / 지점 트리 구조를 제공한다.

각 지점은 학습 콘텐츠를 소화하기 위한 4단계 메뉴를 가진다.

1. 관찰
2. 반복하기
3. 결과물 기록
4. 완료확인
```

세부 학습흐름, 지점 유형, 스킬 유형별 기록 템플릿, 결과물 유형, 완료확인 문항은 별도 문서에서 정의한다.

```text
관련 상세 문서:
LearnCosmos 지점 학습 UX 기획안 v1
```

권장 서버 동기화 경로는 다음과 같다.

```text
docs/plans/LearnCosmos_지점_학습_UX_기획안_v1.md
```
