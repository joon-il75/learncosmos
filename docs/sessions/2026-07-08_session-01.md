# 2026-07-08 session-01

## 주제

공개 홈 Galaxy Map의 은하 조감도 구현 강화

## 사용자 요청

`cosmos.codeghost.cloud` 같은 은하형 화면을 바로 전체 학습 구조까지 구현하기 전에, 먼저 은하 자체만 구현해 보기로 했다.

## 작업 내용

- `frontend/components/landing/PublicCosmosMobileFirstView.tsx`의 Three.js 장면을 은하 우선 레이어 구조로 보강했다.
- CSS 오버레이성 안개 의존도를 낮추고, WebGL 내부에서 밝은 성운 텍스처, 은하 원반 텍스처, 외곽 먼지층, 주 나선팔, 팔 sparkles, 중심부 별무리, 중심핵을 분리했다.
- 초기 조감도 카메라를 더 넓게 잡아 클릭 가능한 학습별보다 은하 전체 형태가 먼저 보이도록 했다.

## 검증

- `npx tsc --noEmit` 통과
- `git diff --check` 통과
- `deploy-frontend.sh` 통과
- `https://www.learncosmos.co.kr/` 200 OK 확인

## 추가 작업: 어두운 3D 은하와 드래그 회전

사용자는 `cosmos.codeghost.cloud` 참고 화면처럼 검은 우주 배경 위에 입자 은하가 떠 있고, 마우스로 은하를 돌려서 볼 수 있는 이미지를 원한다고 설명했다.

이에 따라 공개 홈 Galaxy Map을 밝은 라이트 성운 카드보다 어두운 3D 입자 은하 방향으로 조정했다. Three.js 장면의 은하 레이어를 `galaxyRoot` 그룹으로 묶고, 포인터 드래그로 `galaxyRoot.rotation.x/y` 목표값을 변경해 마우스와 터치에서 은하를 회전할 수 있게 했다.

클릭과 드래그가 충돌하지 않도록 포인터 이동 거리가 5px을 넘으면 별 선택 대신 회전으로 처리한다. 기본 조감도에서는 학습별 라벨 투명도를 더 낮추어 은하 구조가 먼저 보이도록 했다.

검증은 `npx tsc --noEmit`, `git diff --check`, `deploy-frontend.sh`, 공개 홈 200 OK 확인까지 완료했다.

## 추가 작업: 각진 성운 제거와 중심 보라 발광

사용자는 보라색 성운이 너무 각지고 평면처럼 표현되어 삭제하는 것이 좋겠다고 판단했다. 이어서 별의 발광은 은하 중심으로 갈수록 보라색으로 표현하면 좋겠다고 제안했다.

이에 따라 CSS `galaxyVeilStyle` 레이어와 Three.js 성운 Plane을 제거했다. 배경은 어두운 별밭과 입자 은하 중심으로 정리했고, 나선 입자 색상 보간에서 중심부로 갈수록 `#A06CFF`와 `#F0D7FF`가 강해지도록 조정했다. 중심핵과 은하 원반 텍스처도 노란빛보다 보라빛이 더 강하게 보이도록 보정했다.

검증은 `npx tsc --noEmit`, `git diff --check`, `deploy-frontend.sh`, 공개 홈 200 OK 확인까지 완료했다.

## 추가 작업: 코스 별을 은하 내부에 통합

사용자는 은하와 별도로 별들이 떠 있는 것처럼 보이므로, 별 크기를 줄이고 은하 안에 포함되어 함께 회전하길 원했다.

검증은 `npx tsc --noEmit`, `git diff --check`, `deploy-frontend.sh`, 공개 홈 200 OK 확인까지 완료했다.

## 추가 작업: 납작한 은하 원반과 중심 펄스

사용자는 참고 이미지처럼 은하 모양을 더 납작한 원반으로 표현하고, 가운데 펄스가 위아래로 나오게 표현하길 원했다.

검증은 `npx tsc --noEmit`, `git diff --check`, `deploy-frontend.sh`, 공개 홈 200 OK 확인까지 완료했다.

## 추가 작업: 참고 이미지 기반 은하 별무리 재설계

사용자는 참고 이미지처럼 은하 별무리 디자인을 처음부터 다시 해보자고 요청했다. 핵심은 따뜻한 밝은 중심핵, 납작한 파란 외곽 원반, 보라 상단 흐름, 하단 별무리가 하나의 은하 덩어리로 보이는 것이다.

이에 따라 기존 `createSpiralGalaxyLayer`, `createCorePulseLayer` 기반 구성을 제거하고 `createReferenceGalaxyLayer`를 추가했다. 이 함수는 `disk`, `outerArm`, `core`, `upperPulse`, `lowerSparkles` 모드로 입자층을 생성한다. 모든 레이어는 Plane 없이 Points만 사용한다.

검증은 `npx tsc --noEmit`, `git diff --check`, `deploy-frontend.sh`, 공개 홈 200 OK 확인까지 완료했다.
