## 주제

3D 은하 유지와 픽셀아트 코스 별 표현

## 사용자 요청

사용자는 우주 표현을 픽셀아트식으로 하는 방향을 질문했고, 이어서 3D 효과는 그대로 두고 별을 픽셀아트로 표현하는 방안을 요청했다.

## 작업 내용

- 공개 홈 `ThreeCosmosMap`의 3D 은하 배경, Points 은하, 드래그 회전은 유지했다.
- 클릭 가능한 코스 별 텍스처 생성 함수 `createStarTexture`만 픽셀아트 스프라이트풍으로 교체했다.
- 16x16 그리드 기반으로 별 모양을 캔버스에 그리고, `CanvasTexture`에 `NearestFilter`를 적용했다.
- 후광, 궤도 링, 별 sprite scale을 조금 줄여 은하 안에서 과하게 떠 보이지 않도록 했다.

## 추가 작업: 3D 픽셀아트 은하 텍스처

사용자는 생성한 은하 이미지를 3D 픽셀아트로 구현해 보자고 요청했다. 기존 구현은 코스 별만 픽셀아트였으므로, 이번에는 은하 입자와 중심핵 텍스처도 픽셀 블록 기반으로 바꾸었다.

검증은 `npx tsc --noEmit`, `git diff --check`, `deploy-frontend.sh`, 공개 홈 200 OK 확인까지 완료했다.
