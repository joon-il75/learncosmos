## 1. 기획 목적

이 문서는 LearnCosmos의 크리에이터 메뉴를 기존 `07_creator_menu.md` 기준보다 더 상세한 화면, 기능, 권한, 데이터, 구현 단위로 확장하기 위한 계획 문서다.

LearnCosmos의 크리에이터는 단순 강의 판매자가 아니라 학습자가 콘텐츠를 보고 목표와 스킬을 발견할 수 있도록 학습 콘텐츠, 목표물 예시, 스킬 후보, 반복 가이드, 결과물 기준을 설계하는 사람이다.

따라서 크리에이터 메뉴는 콘텐츠 업로드 센터가 아니라 학습경험 설계 센터로 기획한다.

핵심 방향은 다음과 같다.

```text
크리에이터 메뉴
= 콘텐츠 업로드 공간이 아니라
  학습자가 따라갈 수 있는 탐험지점 / 지역 / 행성 설계 공간
```

## 2. 현재 기준 요약

현재 LearnCosmos 기준에서 크리에이터는 P2 확장 기획이다.

초기 메뉴 기준은 다음과 같다.

```text
크리에이터
├─ 크리에이터 소개
├─ 콘텐츠 만들기
├─ 그룹 코스
├─ 내 콘텐츠
└─ 피드백
```

확장 버전은 다음과 같다.

```text
크리에이터
├─ 크리에이터 소개
├─ 콘텐츠 만들기
├─ 그룹 코스
├─ 내 콘텐츠
├─ 피드백
├─ 콘텐츠 분석
├─ 수익화
└─ 정산
```

단, 초기에는 수익화와 정산을 전면에 두지 않는다. 먼저 좋은 학습경험을 설계하고 검증하는 흐름을 우선한다.

## 3. 상세 IA 제안

베타 기준 크리에이터 메뉴는 다음과 같이 정리한다.

```text
크리에이터
├─ 소개
├─ 크리에이터 신청
├─ 콘텐츠 만들기
├─ 내 콘텐츠
├─ 그룹 코스
├─ 학습 반응
└─ 피드백
```

후속 확장 메뉴는 다음과 같이 둔다.

```text
크리에이터
├─ 콘텐츠 분석
├─ 수익화 설정
└─ 정산
```

초기 구현에서는 다음 네 기능만 우선한다.

```text
1. 크리에이터 소개
2. 크리에이터 신청 / 승인
3. 콘텐츠 만들기
4. 내 콘텐츠 관리
```

## 4. 메뉴별 상세 기획

### 4.1 크리에이터 소개

목적은 강의 판매자 모집이 아니라 학습경험 설계자 모집이다.

#### 로그인 전

```text
LearnCosmos 크리에이터는
강의를 판매하는 사람이 아니라,
학습자가 콘텐츠를 보고 목표와 스킬을 발견하도록
탐험지점을 설계하는 사람입니다.

[크리에이터로 시작하기]
```

#### 로그인 후 권한 없음

```text
크리에이터 소개 | 신청하기 | 가이드
```

#### 로그인 후 크리에이터 권한 있음

```text
콘텐츠 만들기 | 그룹 코스 | 내 콘텐츠 | 피드백
```

---

### 4.2 크리에이터 신청

초기 베타에서는 신청 / 승인 구조를 둔다.

```text
크리에이터 신청
→ 프로필 입력
→ 전문 분야 선택
→ 샘플 콘텐츠 제출
→ 운영 검토
→ 크리에이터 승인
→ 콘텐츠 등록 가능
```

#### 신청 입력 항목

```text
1. 기본 정보
- 닉네임
- 소개 문구
- 활동 분야
- 대표 링크

2. 전문 분야
- 초등 학습
- 중고등 학습
- 성인 자기계발
- 코딩 / AI
- 디자인 / 창작
- 언어
- 시험 / 자격증
- 기타

3. 콘텐츠 유형
- 영상 기반
- 글 / 블로그 기반
- PDF / 자료 기반
- 프로젝트 기반
- 문제풀이 기반
- 실습 / 제작 기반

4. 샘플 제출
- URL
- 파일
- 직접 작성 샘플

5. 운영 기준 동의
- 저작권
- 교육적 적합성
- 부적절 콘텐츠 금지
- 외부 링크 품질 기준
- 학습자 보호 기준
```

#### 승인 상태값

```text
draft        신청서 작성중
submitted    검토 대기
needs_update 보완 요청
approved     승인됨
rejected     반려
suspended    일시 제한
```

---

### 4.3 콘텐츠 만들기

크리에이터 메뉴의 핵심 기능이다.

일반 콘텐츠 서비스처럼 제목, 설명, URL만 받는 것이 아니라 LearnCosmos의 지점 학습흐름에 맞춰 다음 구조를 입력하게 한다.

```text
콘텐츠 만들기
= 탐험지점 설계하기
```

#### 생성 단계

```text
1단계. 콘텐츠 기본 정보
2단계. 학습 목표 설정
3단계. 스킬 후보 작성
4단계. 반복 활동 설계
5단계. 질문 / 막힘 포인트 작성
6단계. 결과물 기준 작성
7단계. 자기평가 기준 작성
8단계. 미리보기 / 제출
```

#### 입력 구조

| 구역 | 입력 항목 | 설명 |
|---|---|---|
| 기본 정보 | 제목, 설명, 분야, 난이도, 예상 시간 | 검색 / 추천용 메타 |
| 콘텐츠 자료 | URL, 파일, 본문 입력 | 영상 / 글 / PDF / 직접 작성 |
| 탐험목표 | 학습자가 도달해야 할 목표 | 무엇을 할 수 있게 되는가 |
| 스킬 후보 | 필요한 하위 능력 | 연습 단위로 쪼개기 |
| 반복 가이드 | 따라 할 활동 | 5분 / 10분 / 20분 단위 |
| 질문 포인트 | 예상 막힘 | Lumi / AI 질문 유도 |
| 결과물 기준 | 제출 / 완료 기준 | 포트폴리오화 |
| 자기평가 | 체크리스트 | 학습자 스스로 판단 |

### 4.4 내 콘텐츠

크리에이터가 만든 콘텐츠를 관리하는 화면이다.

```text
내 콘텐츠
├─ 전체
├─ 작성중
├─ 검토중
├─ 공개됨
├─ 보완 필요
└─ 비공개
```

#### 카드 정보

```text
[콘텐츠 제목]
상태: 작성중 / 검토중 / 공개 / 보완필요 / 비공개
유형: 영상 / 글 / PDF / 프로젝트 / 실습
연결된 그룹 코스: N개
학습자 사용 수: N명
완료율: NN%
피드백: N개
마지막 수정: YYYY-MM-DD
```

#### 주요 액션

```text
수정하기
미리보기
복제하기
그룹 코스에 추가
비공개 전환
삭제 요청
```

초기에는 다음 3개 지표만 우선 표시한다.

```text
사용 수
완료율
피드백 수
```

### 4.5 그룹 코스

그룹 코스는 크리에이터가 여러 탐험지점을 묶어 하나의 학습 경로로 만드는 기능이다.

```text
그룹 코스
= 여러 탐험지점을 묶어 하나의 행성 또는 학습 경로로 제공하는 기능
```

#### 그룹 코스 생성 단계

```text
1. 그룹 코스 기본 정보
2. 대상 학습자 설정
3. 콘텐츠 / 탐험지점 선택
4. 권장 순서 설정
5. 각 지점별 목표 / 스킬 확인
6. 완료 기준 설정
7. 공개 범위 설정
8. 미리보기 / 제출
```

#### 공개 범위

```text
비공개
링크 공유
플랫폼 공개
커뮤니티 전용
승인 학습자 전용
```

초기 베타에서는 플랫폼 공개보다 링크 공유 / 커뮤니티 전용을 우선한다.

---

### 4.6 학습 반응

학습 반응은 크리에이터가 단순 조회수보다 학습자가 어디서 막히고 어디까지 완료했는지 확인하는 화면이다.

```text
학습 반응
├─ 많이 완료한 콘텐츠
├─ 중간 이탈이 많은 콘텐츠
├─ 질문이 많이 나온 지점
├─ 반복이 많이 필요한 스킬
└─ 결과물 제출 현황
```

#### 핵심 지표

```text
콘텐츠 조회 수
학습 시작 수
지점 완료 수
평균 완료율
많이 막힌 스킬
자주 나온 질문
결과물 제출 수
```

LearnCosmos에서는 조회수보다 완료율, 질문, 결과물이 더 중요하다.

---

### 4.7 피드백

피드백은 단순 댓글 게시판이 아니라 콘텐츠 개선을 위한 구조화된 피드백으로 설계한다.

```text
피드백
├─ 학습자 질문
├─ 막힌 부분
├─ 개선 요청
├─ 결과물 코멘트
└─ 운영자 보완 요청
```

#### 피드백 상태값

```text
new          새 피드백
reviewing    확인중
resolved     반영 완료
ignored      반영하지 않음
reported     신고 / 검토 필요
```

## 8. MVP 구현 우선순위

### Phase 1 — 메뉴와 신청

```text
- 크리에이터 소개
- 크리에이터 신청
- 신청 상태 확인
- 관리자 승인 / 반려
```

### Phase 2 — 콘텐츠 만들기

```text
- 콘텐츠 기본 정보 작성
- 목표 / 스킬 / 반복 / 결과물 기준 입력
- 작성중 / 검토중 / 공개 상태
- 내 콘텐츠 목록
```

### Phase 3 — 그룹 코스

```text
- 여러 콘텐츠를 묶어 그룹 코스 생성
- 순서 설정
- 공개 범위 설정
- 학습자 입장에서 코스 가져오기
```

### Phase 4 — 피드백 / 학습 반응

```text
- 학습자 피드백 수집
- 완료율 / 질문 / 막힘 지점 확인
- 콘텐츠 개선 흐름
```

### Phase 5 — 수익화 / 정산

```text
- 유료 공개
- 포인트 분배
- 정산 내역
- 환불 / 분쟁 정책
```

초기에는 Phase 1\~2까지만 구현한다.

## 11. Codex 작업 지시문 초안

```text
# 작업 목적

LearnCosmos의 크리에이터 메뉴를 P2 확장 기능 기준으로 설계하고, 초기 구현 가능한 Phase 1\~2 범위를 추가한다.

# 현재 기준

- LearnCosmos는 콘텐츠를 학습 경험으로 바꾸는 AI 기반 자기주도 학습 플랫폼이다.
- 크리에이터는 단순 강의 판매자가 아니라 학습경험 설계자다.
- 크리에이터 메뉴의 기존 하위 구조는 소개 / 콘텐츠 만들기 / 그룹 코스 / 내 콘텐츠 / 피드백이다.
- 수익화와 정산은 초기 전면 기능이 아니라 후속 확장이다.

# 변경 범위

1. 크리에이터 소개 화면
2. 크리에이터 신청 화면
3. 신청 상태 확인 화면
4. 승인된 크리에이터용 홈
5. 콘텐츠 만들기 화면
6. 내 콘텐츠 목록 화면

# 변경하지 말아야 할 것

- 개인학습 핵심 흐름을 깨지 않는다.
- Explorer Diary를 독립 메뉴로 만들지 않는다.
- 수익화 / 정산을 초기 필수 기능으로 넣지 않는다.
- 크리에이터 콘텐츠를 단순 판매 상품처럼 표현하지 않는다.

# 구현 단계

Phase 1:
- 좌측 메뉴 또는 햄버거 메뉴에 크리에이터 진입 추가
- 권한별 크리에이터 화면 분기
- 크리에이터 신청 폼 추가
- 관리자 검토용 최소 상태값 추가

Phase 2:
- 콘텐츠 만들기 폼 추가
- 기본 정보 + 탐험목표 + 스킬 후보 + 반복 가이드 + 결과물 기준 저장
- 내 콘텐츠 목록 추가
- 작성중 / 검토중 / 공개 상태 필터 추가

# API / DB 영향 범위

- creator_profiles
- creator_contents
- creator_content_learning_designs
- creator_feedback
- creator_group_courses는 Phase 3로 보류 가능

# 모바일 UX 고려사항

- 좌측 메뉴는 사용하지 않고 햄버거 메뉴에 크리에이터 메뉴 포함
- 콘텐츠 만들기 폼은 단계형 wizard 또는 accordion으로 제공
- 긴 입력은 자동 저장을 고려

# 테스트 체크리스트

- 비로그인 사용자는 소개 화면만 볼 수 있는가
- 로그인 학습자는 신청 화면으로 이동하는가

- 승인된 크리에이터만 콘텐츠 만들기에 접근 가능한가
- 콘텐츠 임시저장 / 수정 / 검토제출이 가능한가
- 모바일에서 입력 단계가 무너지지 않는가
```

## 13. 최종 판단

크리에이터 메뉴는 지금 당장 수익화까지 확장하지 않는다.

먼저 다음 네 기능을 구현 가능한 기준으로 확정한다.

```text
크리에이터 소개
크리에이터 신청 / 승인
콘텐츠 만들기
내 콘텐츠 관리
```

그 다음 그룹 코스, 학습 반응, 피드백, 수익화 / 정산 순서로 확장한다.

이 순서가 LearnCosmos의 핵심 정체성인 “콘텐츠를 학습 경험으로 바꾼다”와 가장 잘 맞는다.
